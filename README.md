## Overview

Arturia OB-Xa V recreates the Oberheim OB-Xa, the flagship polysynth that defined the big, warm analog sound of 1980s pop and rock with its CEM filter chips and expressive voice architecture.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia OB-Xa V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **CEM Filter** | CEM3320 four-pole low-pass filter per voice with self-oscillation |
| **Unison** | Eight-voice unison stacking for massive pads and leads |
| **Arp/Seq** | Built-in arpeggiator and chord memory for performance use |
| **Vintage Imperfection** | Per-voice tuning drift and component tolerance modeling |
